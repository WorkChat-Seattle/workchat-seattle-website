# Тексты сайта (EN / RU)

Выгрузка Google-таблицы «WorkChat — тексты сайта EN/RU» — источника истины для текстов (CLAUDE.md, ru-version.md). Одна вкладка — один CSV (UTF-8, первая строка — заголовки):

| Файл | Вкладка |
|---|---|
| common.csv | Общее |
| home.csv | Home |
| about.csv | About |
| events.csv | Events |
| event-page.csv | Event page |
| mentorship.csv | Mentorship |
| mentor-info.csv | Mentor info |
| volunteer.csv | Volunteer |
| not-found.csv | 404 |
| seo.csv | SEO |

Колонки: `Ключ` | `Где на странице` | `EN` | `RU` | `Статус` | `Комментарий`.

## Правила
- **Файлы руками не править.** Тексты правят в Google-таблице (Юлия и волонтёры), затем выгрузку обновляют: Юлия просит Claude в проекте WorkChat Seattle «обнови выгрузку текстов» — CSV перезаписываются в этой папке, изменения видны в git diff.
- Из CSV собираются словари `en` / `ru` (скриптом, например `npm run texts:build`). В компонентах — только ключи.
- Строки со статусом «Не переводить здесь» и ключом «—» — пояснения (текст берётся из Notion или другой вкладки), в словарь не попадают.
- Строки со статусом «Черновик» в словарь попадают, но скрипт сборки выводит их списком — чтобы было видно, что ещё не вычитано.
- Если для RU значение пустое — подставлять EN (ru-version.md).
