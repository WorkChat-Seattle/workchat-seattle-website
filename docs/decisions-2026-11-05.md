## 8. Карточка члена команды (card-team-member): био
- Компонент `card-team-member` (`1077:3174`): `state = default | hover` × `color = neutral | light | muted`; hover — тёмный оверлей на всё фото (цвет как в примере, переменная) с белым текстом био (body, отступы 20, обрезка многоточием), текстовое свойство `bio`.
- **Устройства с мышью** (`@media (hover: hover)`): оверлей появляется при наведении и при фокусе с клавиатуры (`:hover`, `:focus-within`), плавно ~0,2 с.
- **Телефоны и планшеты** (нет наведения): оверлей **открывается по нажатию** на фото/карточку и закрывается повторным нажатием, нажатием на другую карточку или Esc. Одновременно открыт только один. Карточка — `<button aria-expanded aria-controls>` (или фото обёрнуто в кнопку), био — элемент с `id`, на который ссылается `aria-controls`; для скринридеров текст био доступен и без открытия (не `display:none`, а визуально скрыт до открытия).
- Био каждого человека — в данных (`data/team.ts`), не в разметке. **Тексты всех троих (Masha Makarenkova, Tatyana Yakushev, Julia Seas) — в секции Figma «Overlays» (`1633:28076`)**: overlay-masha `1582:24723`, overlay-tatyana `1582:24725`, overlay-julia `1582:24727`. С 06.11 подставлены в свойство `bio` всех экземпляров на About (390 / 768 / 1440 / 1920; скрипт `code.team-bios.js`). Био по два абзаца — в данных хранить абзацами; в оверлее возможна обрезка многоточием, полный текст должен оставаться доступным скринридерам.
