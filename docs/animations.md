## Общие правила переноса
- **Без библиотек анимаций.** CSS-переходы и `@keyframes` + один небольшой хук `useInView` (IntersectionObserver) и один общий обработчик прокрутки на `requestAnimationFrame` (параллакс, Our Values). В клиентские компоненты (`'use client'`) выносить только то, что анимируется; содержимое остаётся в серверном HTML.
- **Параметры — токенами** в `@theme` / CSS-переменных (`--ease-btn`, `--duration-btn-in`, `--values-step` …), как в workchat-v2. Одно место для настройки.
- **`prefers-reduced-motion: reduce`** — все анимации выключены, всё сразу на месте (появление, параллакс, плавание аватаров, слайдер и Our Values — мгновенная смена без движения и без закрепления).
- **Без JavaScript контент виден.** Скрытие до появления — только через класс `js` на `<html>` (ставится маленьким inline-скриптом в `<head>` до отрисовки) и `opacity`, не `display: none` / `visibility`. Текст всегда в HTML (seo-ai-visibility.md, п. 5).
- **Анимируем только `opacity` и `transform`** (и `filter` у слайдера, `grid-template-rows` у FAQ). Обработчики прокрутки подключаются только пока секция на экране.
- **Мобильные:** hover-эффекты — только в `@media (hover: hover)`. Параллакс фото и колонки Numbers — только с 1280; на телефонах и планшетах — без них. Появление при прокрутке, FAQ и Our Values — на всех размерах.
- Анимации верстаем **после** того, как страница совпала с макетом в статике, отдельным проходом.

## Список

### 1. Появление при прокрутке (scroll reveal) — все страницы
- Элемент проявляется и поднимается: `opacity 0 → 1`, `translateY(24px) → 0`, **600 ms ease-out**, один раз, когда видно **15%** элемента.
- **Hero** — сразу при загрузке.
- **Очерёдность внутри секции:** соседи в одной строке — с шагом **100 ms** (`--reveal-delay`).
- **Сетки карточек** (What we do, Resource Hub, Get involved): строка появляется целиком, следующая — через **150 ms**; у What we do и Resource Hub все карточки — одной строкой.
- **Группы.** Home: hero (заголовок, текст, фото); what-we-do (заголовок, текст); featured; resource-hub (заголовок); subscribe (карточка, заголовок, текст, форма); testimonials (заголовок, ряд); get-involved (заголовок); footer. About: mission (фото, карточка, текст); values (заголовок, пункты списка, текст); story (заголовок, текст); team (заголовок); FAQ (заголовок, вопросы). Остальные страницы — так же: заголовок секции → текст → блок.

### 2. Кнопки (button dark / white / outlined)
- Заливка hover-цветом **въезжает слева** при наведении и **уходит вправо** при уходе мыши (`::before`, `scaleX(0 → 1)`, `transform-origin` left / right).
- Вход **650 ms**, выход **450 ms**, `cubic-bezier(0.25, 0.1, 0.25, 1)`; цвет текста и рамки — с той же длительностью.
- White: заливка — светлый тон, текст остаётся тёмным. Цвета — из hover-вариантов `button` в Figma.

### 3. Ссылки меню и текстовые ссылки
- Подчёркивание **вырастает слева** при наведении и **уходит вправо**: `scaleX`, **300 ms ease-out**. Линия — ровная, 1px, как в Figma (решение 12.11); рукописную `underline-hover.svg` из v2 не используем.
- У активного пункта меню (`aria-current="page"`) линия видна всегда; у выбранного языка EN/RU — нет.

### 4. Карточки-ссылки (card-square, card-rectangle и подобные)
- Фон → hover-цвет из макета, **300 ms ease-out**; содержимое `scale(1.02)`, **350 ms ease-out**; подчёркивание ссылки въезжает при наведении на всю карточку.
- Карточка на размытом фото: тёмный слой усиливается до `overlay/hover-dark`.

### 5. Логотип
- При наведении три точки в «облачке» прыгают по очереди («печатает…»): `translateY(0 → −3px → 0)`, цикл **1.2 s ease-in-out**, задержки 0 / 0.15 / 0.3 s.

### 6. Шапка при прокрутке
- После **16 px** прокрутки — класс `is-scrolled`: фон `bg/glass` и `backdrop-filter: blur(12px)`; наверху страницы — прозрачная. Без поддержки `backdrop-filter` — непрозрачный фон. Если в Figma иначе — верна Figma.

### 7. Параллакс фото (≥1280)
- **Hero, Featured event, Get involved:** фото сдвигается вниз внутри рамки при прокрутке, без увеличения, **60 px** (`--parallax-shift`); фото выше рамки на эти 60 px.
- **Community (коллаж на Home):** фото сдвигаются с разной скоростью, максимум **120 px**, коэффициент 400 (код в v2).

### 8. Numbers (Home, ≥1280)
- Две колонки цифр едут с разной скоростью (правая быстрее) и **выравниваются по верху, когда секция в центре экрана** (верх на 120 px от верха секции).

### 9. Find your mentor (Home)
Один раз, когда видно 20% секции:
- кольца: `opacity 0 → 1`, `scale(0.9 → 1)`, **450 ms ease-out**, шаг **70 ms**;
- аватары: `scale(0.85 → 1)`, **350 ms**, задержки 400 / 460 / 520 / 580 / 640 / 700 ms, затем бесконечно «плавают» вверх-вниз (амплитуда 10–19 px, период 6–10 s, свой сдвиг по времени — `.mentorship__avatar--NN` в `styles.css` v2);
- заголовок, текст, кнопки: подъём 16 px, **250 ms**, задержки 450 / 500 / 550 ms;
- hover на аватаре (только `@media (hover: hover)`): `scale(1.07)` и ч/б → цвет, **400 ms**. Цветная версия — отдельный PNG `avatar-*-color.png` (скрипт картинок, поле `avatarColor`: исходное фото без saturation из Figma + маска-эллипс + кольцо из stroke узла), лежит поверх ч/б и проявляется `opacity`. Есть у аватаров, которые в макете чёрно-белые (Avatar02, 04, 05, 07, 08) на desktop и tablet; у Avatar03 (в макете цветной) и на mobile — нет.
- Расположение и размеры аватаров — из нового макета.

### 10. Отзывы (testimonials) — слайдер
- Лента — нативный scroll-snap со свайпом (решение Юлии: `translateX` не делаем; длительность прокрутки — браузерная); при движении уходящая и приходящая карточки: `opacity 0.4`, `blur(3px)`; высота плавно подстраивается.
- Невидимые карточки — `inert`; стрелки — `button-round`; точки — `pagination-dot`.

### 11. Our Values (About) — закреплённый блок, ценности сменяются прокруткой
Образец, на который ориентировалась Юлия, — блок ценностей на tresmarescapital.com/en/about. Код — `assets/js/about-values.js` и раздел `about: values` в `styles.css` (workchat-v2).
- **Закрепление:** блок (сцена высотой как в макете) — `position: sticky`, `top: min(0px, 100vh − высота блока)` (на низком окне виден низ блока). Секция выше сцены на **5 × `--values-step`**, `--values-step: 60vh` — прокрутка на 60vh показывает следующую ценность. Номер ценности = `floor(прокручено в закреплении / шаг)`.
- **Загрузка фонов (решено 12.11):** сейчас все пять фонов (в 2×) лежат в разметке стопкой и грузятся сразу. На проходе анимаций грузить только активный и соседний (следующий и предыдущий), остальные — когда до них доходит прокрутка / выбор вкладки; следующее фото предзагружать.
- **Фон:** новое фото проявляется поверх старого сразу, старое гаснет под ним через 600 ms: `opacity`, **600 ms**, кривая `--values-out: cubic-bezier(0.215, 0.61, 0.355, 1)`, у уходящего задержка 600 ms. У каждой ценности своё фото (5 фото, CLAUDE.md, «Блок Our Values»).
- **Параллакс фона:** слой с фото выше сцены на **100 px** (`--values-shift`) и медленно едет вверх, пока блок на экране (подъезд: от −100 до 0, закрепление: от 0 до −100, уход: обратно к 0).
- **Текст описания:** каждое слово в своей маске (`overflow: hidden`). Уходящий текст уезжает вверх (при прокрутке вниз) или вниз (при прокрутке вверх): `translateY(±110%)`, **600 ms** `--values-out`, задержка между словами **10 ms**. Новый текст приезжает с противоположной стороны **через 600 ms**, тоже по словам.
- **Список ценностей:** неактивные — 50% белого (`text/inverse-muted`), активная — белая; смена цвета **400 ms** `cubic-bezier(0.5, 1, 0.89, 1)`; hover — белая (`@media (hover: hover)`).
- **Клик по ценности** — плавная прокрутка к её шагу (`scrollTo` smooth), а не мгновенная смена; без закрепления (reduced motion) — мгновенная смена.
- **Разметка и доступность:** паттерн tabs из CLAUDE.md сохраняется (`role="tablist"`, `tab` + `aria-selected`, `tabpanel`); неактивные панели — `aria-hidden` + `inert`, но **текст всех 5 панелей в HTML**. Слова разбиваются на `<span>` при серверной отрисовке (не через DOM-манипуляции после загрузки), фраза для скринридера читается целиком.
- **Отличия от v2:** в v2 было 3 активные ценности, теперь 5 — шагов 5; раскладка (desktop / tablet / mobile) — из нового макета (CLAUDE.md), тайминги — из v2. Закрепление — **с 768** (tablet и desktop). **На телефоне (< 768) закрепления нет — решение Юлии 13.11:** блок обычной высоты, ценность переключается нажатием на вкладку с той же анимацией текста и фона (слова по маскам, перетекание фона), без параллакса фона. `opacity: 0.95` у сцены из v2 **не переносим** — в Figma у values его нет (проверено 13.11).

### 12. FAQ (About, Mentorship; разделы Privacy Policy)
- Ответ раскрывается по высоте вместе с проявлением: `grid-template-rows: 0fr → 1fr` + `opacity 0 → 1`, **350 ms ease-out**; внутренний блок `min-height: 0; overflow: hidden`.
- У открытого пункта вопрос опускается на 5 px (`padding-top` 40 → 45, **350 ms ease-out**), ответ — на 20 px ниже вопроса.
- Разметка — кнопка с `aria-expanded` (не `<details>`, чтобы анимировать высоту); закрытый ответ — `inert`, но текст в HTML. Первый раздел Privacy Policy открыт при загрузке (privacy-policy.md).
