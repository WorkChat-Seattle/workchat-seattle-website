## Стиль текстов (решено Юлией 06.11)
- **Без феминитивов** («ментор», «эксперт», «специалист», не «менторка», «экспертка», «специалистка»). Обычные слова женского рода, которые есть в языке давно («участница», «основательница»), допустимы.
- **«Менторство»**, не «наставничество».
- **Заимствования можно и нужно**: нетворкинг, воркшоп, вебинар, мастермайнд, менти, референс/реферал.
- Интонация — как у Людмилы Петрановской: короткие фразы, прямо называть трудности («так устроен переезд», «это нормально»), тепло без пафоса и канцелярита, на «вы». Ориентиры среди сообществ — ProWomen By, Women in Tech (ЕГУ), Mentor in Tech.
- **Авторский стиль Юлии (10.11):** чуть более разговорные формулировки в вычитанных текстах — намеренные. Строки со статусом «Вычитано» не переписывать ради «литературности» или параллельности конструкций; предлагать правки только при ошибке смысла, фактической неточности или явной опечатке.
- Заголовки — обычным регистром (Title Case только для EN; в коде `text-transform: capitalize` только для `:lang(en)`; в Figma у RU-текстов textCase = ORIGINAL).
- Даты по-русски: «Среда, 18 ноября 2026»; время — 24 часа, «18:30–20:30»; числа с пробелом-разделителем тысяч: «5 800+», «10 000+». Перед тире — неразрывный пробел.
- **Кавычки в русских текстах — только «ёлочки»** (решено 06.11), вложенные — „лапки“: «слово „внутри“». Не “ ” и не "…". Касается макета, таблицы текстов, RU-полей в Notion и кода. В английских текстах — как было (“ ”).
- **Русские тексты длиннее английских** — блоки должны расти по высоте, а не обрезаться. Заголовки и тексты на mobile — по ширине контента (поля 20) с переносом по словам.
