## og-event (решено 11.11.2026)
- **Слева** фон bg/card-neutral 600×630, **справа** обложка события 600×630 (фильтры как в card-featured-event; источник — Cover photo / обложка из данных события).
- **Логотип** — высота 60 (≈183×60), пропорционально, в (60, 60). У события фокус на названии, а не на логотипе (в общей картинке логотип остаётся 241×80).
- **Текстовый блок** — колонка 480 от x=60, вертикальный auto-layout, **прижат к низу** (низ 570), верх не выше 140 (20 под логотипом). Состав сверху вниз:
  1. **Название** — Google Sans Regular 56 / 90%, −3%, text/heading. EN — Title Case; RU — регистр как есть (из Title RU).
  2. **Краткое описание** (новое, через 20) — Regular 22 / 130%, text/body. EN — Short description, RU — Short description RU (если пусто — английское). **Ограничения по строкам нет** — показываем целиком (решение Юлии 11.11).
  3. **Детали** (через 40) — три строки с иконками 30 (набор `icon` `1036:1384`), между строками 12, текст Regular 22, text/body:
     - дата — `type=date`: EN «Wednesday, 11/18/2026», RU «Среда, 18 ноября 2026»;
     - время — `type=time`: EN «6:30–8:30 PM», RU «18:30–20:30»;
     - место — `type=location`: Place name / город; у онлайн-событий EN «Online», RU «Онлайн» (отдельной иконки для онлайн нет).
- Текстовые свойства компонента: `title`, `description`, `date`, `time`, `place`.
- **Если текст не помещается** (верх блока поднимается выше 140 — длинное название в 3 строки плюс длинное описание): сначала уменьшить название до 44, затем, если всё ещё не помещается, — описание до 20. Текст не обрезать.

## Скрипты (~/Documents/figma-claude-plugin)
- `code.og-build.js` — первая сборка. **Не запускать повторно для OG / Default** — перезапишет ручные правки (шаг `default` в скрипте устарел). Для og-event тоже не запускать — устарел после 11.11.
- `code.og-ru-case.js` (11.11) — отключает Title Case у заголовка RU-картинки.
- `code.og-event-v2.js` → `-fix.js` → `-fit.js` → `code.og-event-logo60.js` (11.11) — текущий og-event: логотип, описание, строка времени, размеры 22, примеры EN/RU. Повторный запуск `code.og-event-v2.js` пересоздаёт примеры, после него нужно снова запустить `-fix`, `-fit` и `-logo60`.

**Шрифт Google Sans есть только на компьютере Юлии** — через Figma MCP тексты с ним не меняются (ошибка «font does not exist»). Тексты правим через локальный плагин «Claude helper (WorkChat)»: скрипт копируется в `code.js` и запускается Plugins → Development → Claude helper (WorkChat) (обычным кликом по меню, фоновое нажатие не срабатывает), отчёт — в `figma.root.getSharedPluginData('claude', 'report')`.

## В коде (Next.js)
- Общая картинка — `app/opengraph-image.png` (экспорт OG / Default, PNG 1×) + `alt`; наследуется всеми страницами.
- Русская версия — экспорт OG / Default / RU как отдельный файл (например `public/og/default-ru.png`); на страницах `/ru/...` в `metadata.openGraph.images` указывать его, `alt` — `seo.ogImage.alt` из словаря `ru` («WorkChat Seattle — помогаем женщинам строить карьеру»).
- События — `app/events/[slug]/opengraph-image.tsx` и `app/ru/events/[slug]/opengraph-image.tsx` через `ImageResponse` (next/og) по раскладке og-event выше; данные из файла событий (RU — Title RU, Short description RU, дата по-русски); шрифт Google Sans — локальный файл; логотип — SVG. Правило «не помещается → уменьшить название, потом описание» — в коде по оценке числа строк.
- `twitter:card = summary_large_image`. Свои `og:title` / `og:description` у каждой страницы.
- После замены картинки обновить кэш в LinkedIn Post Inspector.
