## Как собрано

- **Mobile и 768** — клоны `Event page / Mobile` и `Event page / 768` (How AI) с данными из кадра 1440 этого события: обложка, заголовок, детали (дата, время, место, язык и тип иконки), описание с форматированием (списки, жирный, ссылки), спикеры (имя, био, фото; лишние карточки удаляются), площадка, адрес и карта (заливка map-embed), состояние кнопок Register (disabled у прошедших).
- Нет места (онлайн) → блок Location удаляется. Нет спикеров → блок Speakers удаляется.
- **1920** — клон кадра 1440 шириной 1920; subscribe, get-involved, footer и header берутся из `Event page / 1920`.
- Заодно у How AI в 390 / 768 / 1920 обновлены фото спикеров (раньше там была заглушка).
